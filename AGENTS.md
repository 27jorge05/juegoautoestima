# Convenciones del proyecto

## Antes de cambiar algo

1. Leer `docs/01_tres_raices_autoestima.md` antes de cambiar diseño, mecánicas o contenido.
2. No presentar contenido como terapia, diagnóstico o medición clínica.
3. Mantener separadas las afirmaciones psicológicas verificables de las referencias religiosas o literarias.
4. Registrar las decisiones de diseño que cambien alcance, público, mecánicas o datos.

## Código futuro

- Python 3.11+; Pygame CE solo tras su aprobación explícita.
- Lógica separada de interfaz para facilitar pruebas.
- Sin telemetría, cuentas ni almacenamiento de respuestas personales por defecto.
- Una prueba por cada regla o cálculo nuevo.
